
# Sakha Ikamva Learning Platform

> Building our future, together.

An inclusive, human-centred educational platform developed by Sokhana International Industries (Pty) Ltd as part of the Sakha Ikamva Pilot Programme.

## About the Programme

The Sakha Ikamva Pilot Programme is an 18-month educational and research initiative designed to explore how creative learning, computational thinking, coding and responsibly implemented artificial intelligence can support learner engagement, confidence, transferable skills and educational outcomes.

The programme is intended to support 150 Grade 9 learners from Hector Peterson Secondary School in South Africa.

The platform prioritises inclusive education, particularly supporting learners who experience barriers associated with:

- Dyslexia
- Dysgraphia
- Dyscalculia
- Attention and concentration difficulties
- Communication difficulties
- Low academic confidence

## Our Vision

To create an accessible and supportive digital learning environment where learners can discover their strengths, develop confidence and acquire meaningful skills at their own pace.

The platform is designed around the following principles:

- Inclusive education
- Strengths-based learning

## Getting Started

### Prerequisites

- Node.js 24 LTS
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/AmandaAzania/Sakha-Ikamva-Learning-Platform.git
```

Navigate to the project directory:

```bash
cd Sakha-Ikamva-Learning-Platform
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:5173 in your browser.

### Production Build

```bash
npm run build
```

## Responsible AI and Learner Privacy

The platform is being developed with consideration for learner privacy, child safeguarding, responsible AI and the Protection of Personal Information Act (POPIA).

The current prototype does not collect or transmit personal learner information to a project database or AI service.

Real learner participation, research data collection and AI integration will require appropriate permissions, consent, safeguards and review.

API keys, database credentials and confidential learner information must never be committed to this public repository.

## Development Status
